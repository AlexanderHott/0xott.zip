I want to calculate the value of $$\sum_{i=0}^{500000} i$$.

So like any other person who isn't Gauss and has access to a _high performance_ language like Rust, I wrote a program to calculate it. The only downside with rust is the compile times, so let actually use a C compiler to get the answer.

```rust
use std::{
    fs::OpenOptions,
    io::{BufWriter, Write},
};

fn main() {
    let file = OpenOptions::new()
        .write(true)
        .append(false)
        .create(true)
        .open("./main.c")
        .unwrap();

    let mut writer = BufWriter::new(file);

    let count = 500_000;

    writer.write_all(b"#include <stdio.h>\n\n").unwrap();
    writer.write_all(b"int main(void) {\n").unwrap();
    for i in 0..=count {
        writer
            .write_fmt(format_args!("  long long i{i} = {i};\n"))
            .unwrap();
    }

    writer.write_fmt(format_args!("  long long sum = ")).unwrap();

    for i in 0..count {
        writer.write_fmt(format_args!("  i{i} + \n")).unwrap();
    }
    writer
        .write_fmt(format_args!("  i{};\n\n", count))
        .unwrap();
    writer.write_all(b"  printf(\"%ld\\n\", sum);\n").unwrap();
    writer.write_all(b"}\n").unwrap();
    writer.flush().unwrap();
}
```

Of course! A loop. Why didn't I think of that.

```rust
fn main() {
    let file = OpenOptions::new()
        .write(true)
        .truncate(true)
        .create(true)
        .open("./sum.rs")
        .unwrap();

    let mut writer = BufWriter::new(file);

    let count = 500_001;

    writer.write_all(b"fn main() {\n").unwrap();
    writer.write_all(b"  let mut sum: u64 = 0;\n").unwrap();
    writer
        .write_fmt(format_args!("  for i in 0..={count} {{\n"))
        .unwrap();
    writer.write_all(b"    sum += i;\n").unwrap();
    writer.write_all(b"  }\n").unwrap();
    writer.write_all(b"  println!(\"{sum}\");\n").unwrap();
    writer.write_all(b"}\n").unwrap();
    writer.flush().unwrap();
}
```

```bash
cargo r
```
